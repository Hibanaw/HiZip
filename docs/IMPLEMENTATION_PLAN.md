# 主分支功能实施计划

范围：原生桌面主分支；Web 已移除，鸿蒙不在本轮范围。
不实施：格式转换、批量压缩与解压、撤销与恢复。

## 1. 基础编辑与校验
- [x] 压缩包内文件、文件夹重命名：拒绝非法名称和覆盖，保留子路径与内容，维护外部编辑会话。
- [x] 创建空压缩包：ZIP、7z、TAR 等容器格式；单文件压缩格式仍要求一个源文件。
- 内置文本编辑已按用户要求移除（2026-10-11）；文本预览、外部应用打开及修改写回仍可用。
- [x] 完整性测试：读取全部条目数据，发现密码、损坏及校验错误；不落地解压文件。

## 2. 密码与压缩配置
- [x] 密码解压：密码输入、错误重试、会话内使用，覆盖预览、提取和嵌套打开。关闭压缩包清除服务密码缓存。
- [x] 加密压缩：按引擎能力支持 ZIP AES-256；提交前用密码读取全部数据验证，禁止退化为明文。
- [ ] 文件名加密与 7z 加密：需要单独后端能力，当前界面明确不支持。
- [x] 压缩参数：ZIP Deflate/Store，ZIP/7z 压缩等级 0–9；拒绝无效参数。
- [ ] 其他高级参数：字典大小、固实压缩等按后端能力实现。
- [x] 运行时能力与格式限制：创建菜单按引擎配置能力筛选，AES 不可用时禁用；实际写入错误仍显式报告。

## 3. 分卷
- [x] 创建连续分卷（.zip.001 / .7z.001），设置卷大小，SHA-256 清单，失败清理。
- [x] 自动识别首卷，检测缺卷、大小与校验异常，合并到会话缓存后只读打开。
- [ ] 明确区分连续切分卷、PKZIP .z01 和 RAR 多卷，逐种实现和测试。

## 4. 操作与元数据
- [x] 目标覆盖策略：询问、覆盖、跳过、自动改名，明确文件夹合并行为。
- [x] 任务取消与暂停/继续，提交前失败后重试；中断时清理半成品且保留原包。
- [x] ZIP 注释读取、编辑和重建保留（含条目注释）；其他格式按能力展示。
- [ ] 验证已有嵌套压缩包浏览入口的缓存与修改行为。

宽窗口的列表、图标、多栏和画廊在原文件名位置编辑；紧凑窗口使用 Forui 对话框与统一按钮。默认只选中文件名，保留扩展名；Return 提交、Esc 取消，失败保留输入。macOS 使用 Return 重命名，⌘↓/⌘O 打开所选项目；未选择时 ⌘O 打开压缩包。其他桌面保留 F2 重命名、Enter 打开。

重命名交互更新验证：10 项新增界面测试，以及已有画廊、复制粘贴与拖拽回归，共 20 项通过；静态分析与 macOS Debug 构建通过。

## 浅色配色按用途调整

参考 [VS Code Light Modern](https://github.com/microsoft/vscode/blob/main/extensions/theme-defaults/themes/light_modern.json)、[GitHub Primer](https://primer.style/product/getting-started/react/theme-reference/) 和 [Atlassian 颜色规范](https://atlassian.design/foundations/color)。这些项目分别管理主操作、选中背景、文字与焦点颜色，避免将同一颜色直接用于所有状态。

按用户提供的 Finder 示例，浅色主操作和有色选中状态采用饱和色背景及白色前景。工具栏、设置和文件列表的有色高亮均使用相应主题色，名称、元数据及备用图标使用白色。悬停略微加深，避免 Forui 默认悬停算法造成对比度下降。文字按钮、焦点边框、光标与进度控件直接使用主题色，取消浅色主题色的额外压暗处理。

浅色水印的 Zip 保持中性浅灰 #B0B0B0。深色主题保留既有主题色与选中背景。后续配色应优先调整相应用途，避免用一次整体调亮或调暗同时改变主操作和选中状态。

主题、文件选择与深色切换回归 32 项通过，另有 1 项真实文件行回归验证名称及锁图标选中后变白。六种浅色配色的主按钮和选中控件在普通、实际鼠标悬停状态下，文字对比度均不低于 4.5；文件名称和元数据也通过对比度检查。本次修改文件的静态分析通过。
