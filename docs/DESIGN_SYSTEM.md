# HiZip 设计规范

本规范记录 HiZip 当前的视觉与交互约定，并作为日后抽取组件库 **HiWidget** 的基础。原则是**维持现有 Finder 风格**：安静的中性色界面、一个可更换的强调色、紧凑的桌面密度。

实现入口：[HiWidget 仓库](https://github.com/Hibanaw/HiWidget)（token、调色板与通用布局）与 `lib/ui/desktop_widgets.dart`（主题与控件）。新代码使用 token，不再写字面量。

## 1. 原则

1. **内容优先**：界面是中性的，颜色只用于“可交互”和“已选中”。
2. **一个强调色**：全局只有一个强调色，来自设置。不引入第二个品牌色。
3. **紧凑但不拥挤**：控件高度 28，间距走 4 px 网格，说明文字行高 1.6。
4. **主题完整**：任何颜色在浅色和深色下都要成对定义；文字与线条对背景对比度不低于 4.5:1。
5. **语义优先**：写 `mutedForeground`、`border`，不写十六进制值。

## 2. 颜色

结构色全部来自 Forui `neutral` 主题，不自定义。

| 角色 | 来源 | 用途 |
| --- | --- | --- |
| 背景 `background` | Forui | 文件区、内容区 |
| 面板 `muted` | Forui | 工具栏、侧边栏、标签条、表头 |
| 卡片 `card` | Forui | 按钮底、输入框底、当前标签、弹层 |
| 分隔线 `border` | Forui | 面板边线、行分隔 |
| 文字 `foreground` | Forui | 主要文字 |
| 次要文字 `mutedForeground` | Forui | 表头、说明、元数据、未选标签 |
| 选中（失焦）`secondary` | Forui | 文件区未聚焦时的选中行 |
| 强调色 `primary` | 设置（8 色） | 主要按钮、已启用开关、选中行（蓝色高亮模式）、光标 |
| 强调文字 `desktopAccentForeground` | 由强调色推导 | 强调色用作文字或细线时，向黑/白调整到 4.5:1 |

强调色清单：橙（默认）、蓝、紫、粉、红、黄、绿、灰。填充用原色，文字与描边用推导色，**不要直接把强调色当文字色**。

补充语义色在 `HiColors`：文件夹图标 `folder`、文档图标 `document`、未聚焦选中 `inactiveSelection`、选中行分隔线 `selectionDivider`、图标衬底 `iconPlate`、输入框描边 `inputBorder`、窗口关闭按钮 `closeHover`/`closePressed`。

首页的 “HiZip” 水印颜色由测试固定（浅色 `#B0B0B0`，深色 6% 白），属有意设计，不要随意改动。

## 3. 字体与字号

字体：Windows 用 Segoe UI（回退微软雅黑 UI），macOS 用系统 San Francisco。

| Token | 字号 | 用途 |
| --- | --- | --- |
| `HiText.micro` | 10 | 预览里的等宽文本、小图标网格的名称 |
| `HiText.caption` | 11 | 表头、元数据、信息行、目录标题 |
| `HiText.body` | 12 | 列表、目录树、标签、按钮、说明文字 |
| `HiText.label` | 13 | 小节标题（加粗）、工具栏标题 |
| `HiText.subtitle` | 15 | 检查器中的项目标题（加粗） |
| `HiText.title` | 21 | 设置页标题（加粗） |

- 只有两种字重：常规 400 与强调 600。不使用 500、700。
- 预置样式：`pageTitle`、`sectionLabel`、`itemTitle`、`help`、`secondary`。说明文字使用 `help` 并加上 `mutedForeground`。
- 不新增第七种字号。需要强调时优先用字重或颜色。

## 4. 间距

4 px 网格：`HiSpace.xs 4 / sm 8 / md 12 / lg 16 / xl 24 / xxl 32`，另有 `xxs 2` 仅用于紧贴的细节。

设置页的节奏：

- 页标题 → 第一节：`lg`
- 小节之间：`xl`
- 小节标题 → 控件：`md`
- 控件 → 说明文字：`sm`
- 工具栏控件之间：`sm`

## 5. 形状

| Token | 值 | 用途 |
| --- | --- | --- |
| `HiRadius.control` | 5 | 按钮、输入框、选中行、菜单项、提示条 |
| `HiRadius.surface` | 8 | 所有浮层与面板：对话框、弹出菜单、任务队列与搜索面板、标签页顶部、网格图标衬底 |
| `HiRadius.hairline` | 2 | 滚动条 |

连续多选的行在相连边使用直角，外侧使用 `control` 圆角，中间用半像素分隔线。

## 6. 尺寸

`HiSize`：控件 `control` 28、大控件 `controlLarge` 32、表头 `header` 28、行 `row` 28、标签条 `tabStrip` 36、底部选择条 `strip` 40、设置内容最大宽度 560。

图标：工具栏 17，行内 16–17，小箭头 9–12。图标按钮 30 × 28。

## 7. 控件

- **按钮 `DesktopButton`**：`primary`（强调色填充）每个界面最多一个；`active`（强调色填充，表示已开启）用于开关类，如视图切换；`flat` 用于工具栏；默认为卡片底加细边框。悬停叠加 10%（深色 18%）强调色。
- **图标按钮 `DesktopIconButton`**：必须有 `tooltip`，同时作为无障碍标签。
- **输入框 `DesktopTextField`**：高度随字号计算，聚焦边框为强调文字色。
- **选择 `DesktopSelect`**：用按钮加菜单实现，宽度与触发器一致。
- **标签条与目录树**：当前项在标签条用 `card` 底，在目录树用 `border` 底；不使用强调色。
- **窗口控制按钮（Windows）**：用自绘的 28 高圆角按钮，与工具栏按钮同高同形，不再使用系统样式。靠两点与普通按钮区分：按钮组左侧有一条分隔线；悬停为中性灰（普通按钮悬停带强调色），关闭按钮悬停为纯红。
- **筛选标签**：搜索框收起但仍有关键词时，工具栏显示带清除按钮的灰底标签，让用户知道列表正在被筛选。

## 7.1 窗口与对话框布局

整体布局先于单个组件：同类窗口必须长得一样。

| 场景 | 标题位置 | 内容 |
| --- | --- | --- |
| 独立窗口（设置、属性、创建压缩包、解压选项、密码、重命名、移动/复制、新建项目） | **只在系统标题栏**，格式为 `HiZip · 名称`，内容区不再重复 | 内容顶部直接是表单/信息；底部为分隔线加操作区，主操作在最右 |
| 画面内对话框（宽窗口） | 对话框标题 | Forui 对话框，圆角 8 |
| 紧凑窗口全屏对话框 | 内容区顶部标题加分隔线（没有系统标题栏） | 同上 |
| 信息提示窗口（保存修改？等） | 标题本身是一句提问，保留在内容区 | 说明文字加操作按钮 |

- 浮层（任务队列、搜索、确认面板、菜单）全部使用 `HiRadius.surface`，并通过 Forui 主题的 `md/lg/xl` 统一，不得单独写圆角。
- 浮层贴窗口边缘 8 px，宽度不超过 360。
- 弹窗、面板、窗口内的边距统一为 16 或 20，不使用其他值。

## 8. 交互约定

1. 点击已打开的文件夹（目录树或面包屑）回到该文件夹概览，清除项目选择。
2. 搜索关键词保留到用户主动清除，并始终在界面上可见。
3. 破坏性操作先确认；任务进度显示在底部状态栏，需要用户决定时状态栏脉动提示，并遵从系统“减少动态效果”。
4. 所有可点击元素需要提示文字；菜单项显示快捷键。
5. 紧凑窗口（< 800 宽）对话框全屏，详情通过“属性”查看。
6. 文案先写中文原文，其他语言通过 `translations.dart` 对应，新增文案需补齐全部语言。

## 9. HiWidget 路线图

HiWidget 已独立成仓库（`Hibanaw/HiWidget`），以 git 依赖引入，不依赖 Forui、本地化或应用逻辑。已有 token、`HiPalette`、按钮、工具栏、分栏、设置页、对话框框架、浮层、标签条、筛选标签等通用布局。HiZip 逐步改用它们，迁移顺序：

1. **已完成**：`HiSpace`、`HiRadius`、`HiSize`、`HiText`、`HiColors`。
2. 主题工厂：`desktopTheme`、强调色推导，迁移后接收 `HiAccent`，不依赖应用设置。
3. 基础控件：`DesktopButton`、`DesktopIconButton`、`DesktopTextField`、`DesktopSelect`、`DesktopSlider`、`DesktopDialog`，改名为 `Hi*`。
4. 组合组件：筛选标签、设置分组、信息行。
5. 文案不进入组件库：组件接收已翻译的 `Widget`/`String`，由应用负责本地化。

迁移规则：一个组件进入 HiWidget 前，必须在 HiZip 中至少有两处使用、有测试、且不引用应用状态。
