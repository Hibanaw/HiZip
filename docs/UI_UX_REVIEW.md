# UI/UX 检查（2026-10-10）

本次检查覆盖压缩包浏览工作区、目录树、详情栏、搜索、视图切换及注释编辑。依据当前实现与 Flutter 控件测试；未进行各平台实机验收。

## 已完成：Information 内联注释

- ZIP 根目录 Information 的 Status 下一行显示 Comment，与其他信息行使用相同布局。
- 无注释时，Comment 右侧显示 No comment；有内容时另起一行，默认预览四行，超出时显示省略号。
- 点击省略号展开全文，再次点击可收起；只读 ZIP 也可展开查看。
- 点击正文或 No comment 原位进入多行文本框，输入框随内容自动增高。下方提供保存按钮，点击其他位置也自动保存。
- 保存失败显示错误并保留草稿；即使切换目录再返回，也可继续修改或重试。保存前检查 ZIP 注释的 UTF-8 字节上限。
- 保存、清空后立即刷新详情；选中文件、文件夹或进入子目录后不显示压缩包注释。
- 移除原独立注释区、编辑/查看按钮和文件菜单的注释弹窗入口。只读 ZIP 不提供编辑；其他格式不显示此行。
- 补充中文、英文及其他五种界面语言的文案。

## 已完成：详情样式、属性与搜索布局

- Comment 的标签与正文直接使用 Information 其余信息行的字体、字号、行高和颜色。
- 列表、图标、多栏、画廊详情栏统一使用原 Gallery 的背景色，底部操作区也保持一致。
- 项目、目录树根目录和文件区空白处的右键菜单增加“属性”。属性使用与设置相同的独立原生窗口机制，复用 Gallery 详情布局与内容，包括摘要图标、Information、操作按钮及根目录 Comment；窄窗口也可使用，主窗口继续接受操作。
- 属性窗口只接收详情元数据及最多三个摘要图标，避免跨窗口复制大型压缩包的全部条目。保存和操作通过窗口通信交给主窗口，目标固定为打开属性时的压缩包与项目。系统关闭按钮在隐藏窗口前尝试保存注释，失败时保留窗口与草稿。
- 常规桌面布局的搜索框在工具栏下方单独展开。工具栏内的路径、视图开关和按钮保持原位置，紧凑窗口继续使用原搜索布局。

## 已完成：菜单栏整理与功能覆盖

- macOS 菜单栏与其他平台的应用菜单共用同一份功能定义，按文件、编辑、显示、前往分组。移除模板遗留的拼写、替换、朗读、文本变换、匹配样式粘贴及空帮助菜单，并移除失效的旧注释弹窗命令。
- 补齐打开所选、打开方式、快速查看、解压所选/当前文件夹/全部/同名目录、空压缩包、内置文本编辑、属性、搜索等入口；创建格式跟随引擎实际支持的格式。
- 增加添加文件/文件夹、移动到/复制到的菜单入口。移动与复制使用压缩包内目录选择，排除自身、子目录和没有效果的目的地。
- 属性查看保留当前文件选择；压缩包属性直接展示根目录信息和 Comment，不依赖右键或清空选择。
- 提供各视图、排序字段与方向、图标大小、预览栏、任务列表、返回、上级目录、根目录、标签页切换的菜单入口，并同步当前勾选状态。
- 多选、只读、锁定文件、正在执行操作或打开模态对话框时，菜单根据实际条件禁用不适用操作。独立窗口只接收自己的文本编辑命令，主窗口文件命令禁用。
- 菜单中的常用快捷键同步至应用内键盘处理；文本焦点下的复制、粘贴、全选、剪切与撤销/重做保留文本编辑语义。

## 待改进的问题（按优先级）

### 1. P2：点击当前目录无法回到该目录的详情

复现：在根目录选中项目，再点击目录树中的根目录。文件选择仍保留，详情栏继续显示所选项目，根目录信息和注释没有出现。

原因：`ArchiveWorkspace.navigate` 在 `next == folder` 时直接返回；目录树点击调用同一方法。

建议：用户显式点击目录树或面包屑中的当前目录时清除项目选择，显示该目录的详情。画廊首次自动选择项目，也应提供明确的目录概览入口。

### 2. 已解决：紧凑窗口没有详情入口

通过菜单栏、应用菜单、右键或长按菜单的“属性”，现在可以在紧凑窗口查看 Gallery 布局的详情与根目录注释。预览栏仍只在宽窗口显示。

### 3. P2：搜索框关闭后无法看见正在使用的关键词

复现：输入搜索词，点击搜索框外侧或按 Esc。搜索框收起，文件仍被筛选；仅搜索图标有激活状态。

原因：`closeCompactSearch` 只修改 `compactSearchOpen`，保留 `search.text`。现有测试也明确验证保留查询。

建议：保留查询行为，但在工具栏显示包含关键词的筛选标签及清除按钮。用户应能辨认当前展示的是筛选结果。

### 4. P2：列表表头和目录树仍缺少直接键盘操作

现象：列表列标题与目录树展开、选择依赖 `GestureDetector.onTap`。列标题未提供可聚焦的按钮或排序状态语义；目录树行的 `Semantics` 只标记选中状态，未提供相应语义操作。

菜单已提供排序字段、方向和目录导航入口。表头和树节点仍需补充焦点、Enter/Space 操作、展开状态与排序状态语义，以及目录树方向键导航。
